# HealthHub 🏥

A responsive health information platform built with **Next.js, TypeScript, and Tailwind CSS**. HealthHub helps users explore health-related articles, search for information, browse categories, and stay informed about health and wellness.

🌐 **Live Demo:** https://health-hub-orpin.vercel.app/

📁 **GitHub Repository:** https://github.com/UgoEmax/health-hub

## Features

- **Health Articles:** Browse health-related articles.
- **Search:** Search for articles by keyword.
- **Category Filtering:** Filter articles by health category.
- **Article Details:** View individual article pages.
- **Pagination:** Navigate through paginated article results.
- **Newsletter Form:** Submit an email through a validated form.
- **Loading, Error & Empty States:** Clear feedback while data loads or when results are unavailable.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.
- **Accessibility:** Semantic HTML and accessible form controls.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/UgoEmax/health-hub.git
```

### 2. Navigate into the project directory

```bash
cd health-hub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

To create a production build, run:

```bash
npm run build
```

To start the production server after building:

```bash
npm start
```

## API Integration

HealthHub uses the [DummyJSON Posts API](https://dummyjson.com/posts) to retrieve article data.
